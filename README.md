# Abdullah Latif — Portfolio (Next.js)

This is the Next.js (App Router) migration of the original TanStack Start
portfolio project. The UI, layout, styling, animations and content are
unchanged — only the underlying framework moved from TanStack Start/Router to
Next.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — home page (Hero, About, Work, Achievements, Contact)
- `/projects` — full projects archive

## Build

```bash
npm run build
npm run start
```
